# Apex — tracker MTT Winamax

Tracker de tournois **MTT Winamax** pour Windows : résultats, primes (Space KO, KO, Mystery), chance, et surtout le travail de ton jeu (spots, ranges jouées, BB/100, revue des tapis face à Nash, fuites, comparaison avec les regs).

## 1. Installer

1. Lance `Apex-setup.exe`.
2. Windows affiche « Windows a protégé votre ordinateur » : c'est normal, l'application n'est pas encore signée.
   - Clique sur **Informations complémentaires**.
   - Puis clique sur **Exécuter quand même**.
3. L'installation se fait dans ta session, sans droits administrateur. Apex s'ouvre à la fin.

## 2. Importer tes tournois

- Apex trouve tout seul le dossier d'historiques de Winamax sur ton PC.
- Clique sur **Importer maintenant**. Compte quelques secondes pour quelques centaines de tournois.
- Rien n'apparaît ? Vérifie que l'enregistrement de l'historique des mains est activé dans les réglages de Winamax.
- Tu peux aussi glisser un dossier d'historiques sur la fenêtre.
- Seuls les **tournois MTT** sont lus. Les Expresso sont ignorés.

## 3. Pendant que tu joues

- L'**import automatique** relit ton dossier toutes les minutes : tes tournois arrivent tout seuls.
- Le bouton **Ouvrir le HUD** (en bas à gauche) ouvre une petite fenêtre toujours au premier plan. Elle affiche :
  - tes tables en cours ;
  - pour chaque adversaire déjà croisé : ses stats (VPIP / PFR / 3-bet), ta pastille et ta note.

## 4. Où trouver quoi

| Je veux… | Onglet |
|---|---|
| Voir combien je gagne | Résultats |
| Savoir si j'ai eu de la chance | Chance & variance |
| Voir mes primes Space KO, KO, Mystery | Primes |
| Revoir un tournoi, ses KO, ses mains clés | Tournois |
| Comprendre comment je joue | Mon jeu |
| Trouver ce qui me coûte de l'argent | Fuites |
| Rejouer une main | Mains |
| M'entraîner au tapis ou fold | Entraînement |
| Calculer l'ICM, une équité, une prime | Outils |
| Gérer ma bankroll | Bankroll & objectifs |

Sur chaque écran, le bouton **?** en bas à gauche explique comment le lire.

## 5. Tes données

- Tout reste sur ton PC : rien n'est envoyé sur internet.
- La remise à zéro (Réglages) efface seulement les données d'Apex, jamais tes historiques Winamax.
